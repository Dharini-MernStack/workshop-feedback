```bash
cd "/Users/dharinisrinivasan/Desktop/Dharini - SRM AP planning/workshop-tool"
```

## Before the Workshop
1. Run the app
2. Go to ⚙️ Setup → paste your Groq API key
3. Test Demo 1 (Roast My Resume) works
4. Add your Colab/Form links in 🔗 Quick Links
5. You're ready!
